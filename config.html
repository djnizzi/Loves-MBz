Choose the fields the Tag from MusicBrainz window offers, and whether its button sits on MediaMonkey's toolbar. Each row says where it is written: a tag the file carries (extended tag), or one of MediaMonkey's own fields. A field you turn off here is not offered in any window until you turn it back on; the ticks in Fields to write still decide what this Apply writes. The toolbar switch takes effect the next time MediaMonkey starts — the button is added at start-up, and the action keeps its menu entries either way.
